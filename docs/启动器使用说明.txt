新手先确认
----------

本工具不包含 VRCT 与 New API 软件本体。安装前必须分别下载好 VRCT 和 New API，并在安装器中选择它们的可执行文件。

New API 还必须配置一个真正可用的在线 API 渠道或本地模型。本工具不会自动提供模型、第三方 API 账号或免费 API 令牌。

如果还没有准备好，请先打开安装包第一层的“00-先看这里.txt”，从“使用前准备”开始按顺序操作。

一键启动
--------

点击“一键启动”后，启动器会依次：

1. 检查 http://127.0.0.1:3000 的 New API 状态。
2. 在需要时隐藏启动 New API，并等待初始化完成。
3. 检查 http://127.0.0.1:1234 的兼容中转状态。
4. 在需要时使用内置运行时隐藏启动兼容中转。
5. 启动 VRCT。
6. 将启动器最小化。
7. 监控 VRCT；VRCT 退出后结束本次由启动器启动的后台服务。

配置令牌
--------

1. 在 New API 网页中创建可用令牌。
2. 打开 VRC 翻译启动器。
3. 点击“配置 New API 令牌”。
4. 在本机网页中粘贴令牌。
5. 点击“验证并保存”。
6. 验证成功后，令牌会使用 Windows DPAPI 加密保存。

VRCT 设置
---------

翻译引擎：LM Studio
LM Studio 地址：http://127.0.0.1:1234/v1
模型：安装器中填写的模型名称之一

模型切换
--------

安装器最多保存三个模型名称。它们必须与 New API 的模型名称或别名完全一致。可将快速、均衡和高质量模型分别填入三个位置，再在 VRCT 中按场景选择。

按钮说明
--------

一键启动：启动并连接整套翻译流程。
配置 New API 令牌：打开本机安全配置页。
打开 New API：进入 New API 管理网页。
停止本次后台服务：结束本次由启动器启动的 New API 和中转。
打开安装目录：查看启动器、中转和配置文件。
查看使用说明：打开本文件。

常见问题
--------

New API 45 秒内未就绪：
先单独打开 New API，访问 http://127.0.0.1:3000 完成首次初始化。

兼容中转无法启动：
检查 1234 端口是否被 LM Studio 或其他程序占用。

模型列表为空或翻译失败：
检查 New API 令牌、渠道状态、模型名称和模型别名。

VRCT 没有自动配置：
先运行并关闭一次 VRCT，再重新运行安装器。

其他玩家语音识别不准：
检查扬声器捕获设备，降低游戏背景音乐，调整 VRCT 的静音结束时间、转录间隔和最小单词数，并选择适合目标语言的 Whisper 模型。
