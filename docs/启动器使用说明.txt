一键启动
--------

点击“一键启动”后，启动器会依次：

1. 检查或启动 New API（127.0.0.1:3000）
2. 检查或启动兼容中转（127.0.0.1:1234）
3. 启动 VRCT
4. 将启动器最小化
5. 在 VRCT 退出后关闭本次由启动器启动的后台服务

配置令牌
--------

如果安装时没有填写 New API 令牌：

1. 先在 New API 网页中创建可用令牌。
2. 打开“VRC 翻译启动器”。
3. 点击“配置 New API 令牌”。
4. 在本机网页中粘贴令牌并验证保存。

VRCT 设置
---------

翻译引擎选择 LM Studio。
LM Studio 地址填写：http://127.0.0.1:1234/v1
模型选择安装器中填写的模型名称之一。

常见问题
--------

New API 45 秒内未就绪：
请先单独运行 New API，打开 http://127.0.0.1:3000 完成首次初始化。

兼容中转无法启动：
检查 1234 端口是否被 LM Studio 或其他软件占用。

模型列表为空或翻译失败：
检查令牌是否有效，以及安装器中填写的模型名称是否与 New API 完全一致。

VRCT 没有自动配置：
先运行并关闭一次 VRCT，让它生成 config.json，再重新运行轻量安装器。
