====================

项目简介
--------

本工具用于把 VRCT、New API 和翻译模型连接成一套容易安装、容易启动的 VRChat 实时翻译方案。

使用者在 VRCT 中说话时，VRCT 负责语音识别，中转负责整理翻译请求，New API 负责调用已配置的在线或本地模型，最终译文由 VRCT 发送到 VRChat。接收其他玩家语音时，也可由 VRCT 完成识别并在界面或 VR Overlay 中显示译文。

主要功能
--------

1. 图形化安装器：选择 VRCT.exe 和 New API.exe 后自动完成安装。
2. 图形化启动器：一键启动 New API、兼容中转和 VRCT。
3. 隐藏后台运行：New API 与中转不占用任务栏窗口。
4. 自动结束服务：关闭 VRCT 后，启动器会结束本次由它启动的后台服务。
5. 三模型选择：最多配置三个 New API 模型或模型别名，并在 VRCT 中切换。
6. 自动配置 VRCT：将 LM Studio 接口设置为 http://127.0.0.1:1234/v1。
7. 配置备份：修改 VRCT config.json 前自动创建带时间戳的备份。
8. 严格翻译模式：温度固定为 0，只输出译文，不回答问题，也不会因为“不要翻译”等句子停止翻译。
9. 上下文翻译：保留最近最多 15 条短上下文，用于判断语气、指代、敬语和俚语。
10. 语音识别纠错：结合上下文修正高置信度的同音字、断句、重复片段和词边界错误。
11. 安全令牌配置：通过本机网页验证 New API 令牌，并使用 Windows DPAPI 加密保存。
12. 本机回环通信：中转监听 127.0.0.1，VRCT、New API 和中转在本机完成连接。

工作流程
--------

VRCT
  ↓ OpenAI / LM Studio 格式请求
兼容中转：http://127.0.0.1:1234/v1
  ↓ 请求整理、上下文合并、严格翻译规则
New API：http://127.0.0.1:3000/v1
  ↓ 根据渠道与模型别名调用模型
翻译模型
  ↓ 返回单一译文
VRCT / VRChat OSC / VR Overlay

使用前准备
----------

1. 下载并解压 VRCT：
   https://github.com/misyaguziya/VRCT/releases/latest

2. 下载并准备 New API：
   https://github.com/QuantumNous/new-api/releases/latest

3. 首次打开 New API，在浏览器中完成管理员初始化、渠道和令牌配置。

4. 先运行一次 VRCT 后正常关闭，让 VRCT 生成 config.json。

安装方法
--------

1. 双击“安装 VRC 翻译助手.exe”。
2. 选择 VRCT.exe。
3. 选择 New API 的可执行文件。
4. 确认安装位置。
5. 填写 New API 中实际可用的模型名称或模型别名，最多三个。
6. New API 令牌可以在安装时填写，也可以安装后通过启动器配置。
7. 点击“一键安装”。
8. 安装完成后打开“VRC 翻译启动器”。

首次启动
--------

1. 点击“一键启动”。
2. 等待 New API 和兼容中转状态变为“运行中”。
3. VRCT 会自动启动，启动器随后最小化。
4. 在 VRCT 的翻译引擎中选择 LM Studio。
5. LM Studio 地址使用：http://127.0.0.1:1234/v1
6. 模型选择安装器中填写的模型名称之一。
7. 在 VRChat 中开启 OSC，并根据需要启用聊天框或 VR Overlay 输出。

配置 New API 令牌
------------------

1. 在 New API 网页创建可用令牌。
2. 打开 VRC 翻译启动器。
3. 点击“配置 New API 令牌”。
4. 在本机配置页粘贴令牌。
5. 点击“验证并保存”。
6. 验证成功后重新测试 VRCT 模型列表和翻译。

模型填写规则
------------

- 模型名称必须与 New API 的模型名称或模型别名完全一致。
- 可以填写在线模型，也可以填写由 New API 转发的本地 OpenAI 兼容模型。
- 只使用一个模型时，可将模型 2 和模型 3 留空。
- 建议分别配置快速模型、均衡模型和高质量模型，便于在延迟与翻译质量之间切换。

常见问题
--------

New API 45 秒内未就绪：
先单独打开 New API，访问 http://127.0.0.1:3000 完成首次初始化。

兼容中转无法启动：
检查 1234 端口是否被 LM Studio 或其他程序占用。

模型列表为空：
检查 New API 令牌、渠道状态、模型名称和模型别名。

VRCT 没有自动配置：
先运行并关闭一次 VRCT，再重新运行安装器。安装器会在修改前备份 config.json。

自己的语音能翻译，但其他玩家语音不稳定：
检查 VRCT 的扬声器输入设备、语音接收结束后的静音时间、转录间隔、最小单词数和游戏背景音乐音量。背景音乐较大时会明显影响外部语音识别。

长句在 VRChat 聊天框中显示不全：
VRChat 聊天框本身有长度限制。可缩短单次语音、开启 VR Overlay，或将长句拆成几段发送。
