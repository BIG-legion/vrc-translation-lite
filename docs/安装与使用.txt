使用前准备
----------

1. 下载并解压 VRCT：
   https://github.com/misyaguziya/VRCT/releases/latest

2. 下载并准备 New API：
   https://github.com/QuantumNous/new-api/releases/latest

3. 首次使用 New API 时，请先打开它，在浏览器中完成管理员初始化、渠道和令牌配置。

4. 建议先运行一次 VRCT 后正常关闭，让 VRCT 生成 config.json。这样安装器可以自动备份并配置它。

安装方法
--------

1. 双击“安装 VRC 翻译助手.exe”。
2. 选择 VRCT.exe 和 new-api*.exe。
3. 填写 New API 中实际可用的模型名称或模型别名，最多三个。
4. New API 令牌可以直接粘贴，也可以留空，安装后通过启动器配置。
5. 点击“一键安装”。
6. 安装完成后使用“VRC 翻译启动器”。

正常工作时
----------

- New API 默认地址：http://127.0.0.1:3000
- 兼容中转地址：http://127.0.0.1:1234
- VRCT 的 LM Studio 地址：http://127.0.0.1:1234/v1
- New API 和兼容中转隐藏运行，不单独显示任务栏窗口。
- 关闭 VRCT 后，启动器会关闭本次由它启动的后台服务。

--------

- 这不是 VRCT 或 New API 官方安装器。
