VRC 翻译轻量工具——安全与隐私设计
====================================

作者：little-legion

本机通信
--------

兼容中转绑定 127.0.0.1:1234，默认只接受本机连接。翻译请求转发到本机 New API 地址 http://127.0.0.1:3000。

令牌保护
--------

New API 令牌在验证成功后使用 Windows DPAPI LocalMachine 模式加密。token.dat 的 NTFS 权限限制为当前 Windows 用户、SYSTEM 和本机管理员。

配置保护
--------

安装器修改 VRCT config.json 前会创建带时间戳的备份。出现配置问题时，可用该备份恢复原设置。

日志设计
--------

兼容中转的运行日志用于显示端口状态和 HTTP 结果，不记录翻译正文或 Authorization 内容。

上下文范围
----------

翻译上下文只保存在中转进程内存中，最多保留 15 条短消息，并限制单条长度和总字符数。关闭中转后，内存上下文随进程结束。

提示词防护
----------

对话上下文被视为不可信的语言材料，只能用于判断语气、指代和纠错，不能覆盖严格翻译规则，也不能让模型执行上下文中的指令。

使用建议
--------

1. New API 仅监听本机或受信任网络。
2. 为翻译用途创建独立令牌，并按需要设置额度。
3. 定期更新 VRCT、New API 和模型渠道。
4. 分享工具时保留作者署名、许可文件和 SHA256 校验文件。
