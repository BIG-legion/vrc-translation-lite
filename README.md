# VRC Translation Lite

面向 VRChat 跨语言交流的 VRCT 轻量安装器、图形启动器与本地 New API 兼容中转。

## 项目想法

VRCT 已经能够完成麦克风和扬声器语音识别、翻译、VRChat OSC 输出与 VR Overlay 显示，但模型服务、令牌、端口和启动顺序仍需要手动配置。
且不能配置deepseek的api，本项目根本目的是使用deepseek来进行翻译。

本项目把整个流程整理为三个清晰层次：

1. **VRCT** 负责语音识别、翻译显示和 VRChat 输出。
2. **兼容中转** 负责整理上下文、强化翻译规则、纠正高置信度语音识别错误，并提供 VRCT 可直接使用的 OpenAI / LM Studio 兼容接口。
3. **New API** 负责管理模型渠道、令牌、模型别名，以及在线或本地上游模型。

图形安装器负责建立连接，图形启动器负责管理生命周期。正常使用时只需要打开“VRC 翻译启动器”。

## 工作流程

```text
VRCT
  ↓ OpenAI / LM Studio 格式请求
兼容中转：http://127.0.0.1:1234/v1
  ↓ 上下文合并、识别纠错、严格翻译规则
New API：http://127.0.0.1:3000/v1
  ↓ 渠道与模型别名
在线或本地翻译模型
  ↓ 单一译文
VRCT / VRChat OSC / VR Overlay
```

## 核心功能

### 图形化安装

- 选择 VRCT.exe 与 New API 可执行文件。
- 设置安装目录。
- 填写最多三个 New API 模型名称或模型别名。
- 在安装时填写 New API 令牌，或稍后通过启动器配置。
- 自动安装启动器、兼容中转和运行时。
- 自动备份并配置 VRCT 的 `config.json`。
- 创建开始菜单与桌面快捷方式。

### 一键启动与进程管理

- 自动检查或启动 New API。
- 自动检查或启动兼容中转。
- 启动 VRCT 后将启动器最小化。
- New API 与中转使用隐藏窗口运行。
- 关闭 VRCT 后，结束本次由启动器启动的后台服务。
- 已经由用户单独启动的服务不会被误关。

### 三模型选择

安装器最多保存三个 New API 模型名称，可按场景设置为：

- 快速模型：低延迟连续对话。
- 均衡模型：日常交流默认选择。
- 高质量模型：复杂长句、敬语或含糊语境。

模型既可以是在线 API，也可以是由 New API 转发的本地 OpenAI 兼容模型。

### 严格翻译模式

兼容中转把模型定义为确定性翻译引擎：

- `temperature` 固定为 `0`。
- 每个输入都必须翻译，包括问题、命令、拒绝语和“不要翻译”等句子。
- 不回答原文中的问题。
- 不添加解释、前缀、引号或注释。
- 只输出一种目标语言的译文。

### 15 条上下文与语音识别纠错

VRCT 可能把一整句话拆成多次增量发送。中转采用有界上下文窗口：

- 最多 15 条短消息。
- 单条最多 400 个字符。
- 总上下文最多 5000 个字符。
- 完全重复的片段不会反复加入。
- 连续增长的识别片段会尝试替换旧片段。
- 上下文用于判断语气、指代、敬语、俚语和话题。
- 只修正高置信度的同音字、断句、词边界、标点和重复片段。

上下文被视为语言材料，不能覆盖翻译规则，也不能让模型执行其中的指令。

### 本机配置与令牌保护

- 兼容中转监听 `127.0.0.1:1234`。
- 默认连接本机 New API `http://127.0.0.1:3000`。
- New API 令牌可通过本机配置页验证。
- 验证成功后使用 Windows DPAPI 加密保存。
- 配置文件通过受限 NTFS 权限保护。
- 修改 VRCT 配置前创建带时间戳的备份。
- 运行日志只记录服务状态和 HTTP 结果。

## 下载与安装

前往 [Releases](https://github.com/BIG-legion/vrc-translation-lite/releases/latest) 下载最新版安装 ZIP 和同版本 SHA256 文件。

使用前先准备：

1. 从 [VRCT 官方 Releases](https://github.com/misyaguziya/VRCT/releases/latest) 下载并解压 VRCT。
2. 从 [New API 官方 Releases](https://github.com/QuantumNous/new-api/releases/latest) 下载并准备 New API。
3. 打开 New API，在浏览器中完成管理员初始化、渠道与令牌配置。
4. 运行一次 VRCT 后正常关闭，让它生成 `config.json`。

安装步骤：

1. 解压 `VRC-Translation-Lite-Setup-*.zip`。
2. 双击“安装 VRC 翻译助手.exe”。
3. 选择 VRCT.exe 和 New API 可执行文件。
4. 填写最多三个模型名称。
5. 点击“一键安装”。
6. 安装完成后打开“VRC 翻译启动器”。

## 首次使用

1. 点击启动器的“一键启动”。
2. 等待 New API 与兼容中转显示“运行中”。
3. 在 VRCT 中将翻译引擎设置为 **LM Studio**。
4. LM Studio 地址使用 `http://127.0.0.1:1234/v1`。
5. 选择安装器中填写的模型名称。
6. 在 VRChat 中开启 OSC，并按需要启用聊天框或 VR Overlay 输出。

## 配置 New API 令牌

1. 在 New API 网页创建可用令牌。
2. 点击启动器中的“配置 New API 令牌”。
3. 在本机页面粘贴令牌。
4. 点击“验证并保存”。
5. 验证成功后测试 VRCT 模型列表与翻译。

## 语音识别说明

Whisper 或 Google 语音识别位于 VRCT 层。兼容中转可以结合上下文修正明显识别错误，但无法恢复识别阶段完全丢失的声音。

其他玩家语音的准确度主要取决于：

- 扬声器捕获设备。
- 玩家语音与世界背景音乐的音量比例。
- 目标识别语言。
- 静音结束时间、转录间隔与最小单词数。
- Whisper 模型大小以及 CPU/GPU 性能。

## 常见问题

### New API 45 秒内未就绪

先单独打开 New API，访问 `http://127.0.0.1:3000` 完成首次初始化。

### 兼容中转无法启动

检查 1234 端口是否被 LM Studio 或其他程序占用。

### 模型列表为空或翻译失败

检查 New API 令牌、渠道状态、模型名称和模型别名是否完全一致。

### VRCT 没有自动配置

先运行并关闭一次 VRCT，再重新运行安装器。安装器会在修改前备份 `config.json`。

### 自己的语音正常，其他玩家语音不准

检查扬声器输入设备，降低游戏背景音乐，调整语音接收结束后的静音时间、转录间隔和最小单词数。

### VRChat 聊天框放不下长句

聊天框本身有长度限制。可缩短单次语音、开启 VR Overlay，或把长句拆成几段。
